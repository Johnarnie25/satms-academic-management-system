# Student Academic Tracking Management System (SATMS)

## Overview

A scalable full-stack academic management system developed as a capstone project, designed for real-world institutional use. The platform centralizes academic data and provides role-based access for administrators, teachers, students, and parents to efficiently manage and monitor academic performance.

## Features

* Role-based access control (Admin, Teacher, Student, Parent)
* Academic record management and tracking
* Secure authentication with CAPTCHA validation
* Structured data management for accuracy and consistency
* Optimized database queries and indexing for improved performance
* Centralized system for managing academic workflows

## Tech Stack

* (PHP)
* JavaScript
* MySQL
* HTML / Bootstrap
* REST API Integration
